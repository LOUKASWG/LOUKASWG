## 🧠 Engineering Mindset

What I value while learning and building software:

* **Understand before memorizing** — learning the reasoning behind concepts instead of only syntax.
* **Fundamentals matter** — algorithms, data structures, databases and systems are the foundation of good software.
* **Break complex problems down** — turning large problems into smaller, understandable parts.
* **Learn by building** — transforming theory into working implementations.
* **Document the process** — keeping code and knowledge organized so they can be revisited and improved.
* **Continuous improvement** — treating every project as an opportunity to write better code than the previous one.
